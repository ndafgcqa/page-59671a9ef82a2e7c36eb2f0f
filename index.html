使用场景

流媒体与内容访问

旗舰版与团队版针对常见流媒体平台做了原生解锁优化，适合追剧、听播客或查阅海外资料。合理选择节点地区可降低卡顿。

IPLC 专线有助于降低部分游戏线路的抖动。建议在客户端中为游戏进程设置独立策略，避免与大流量下载抢带宽。

远程办公与协作

团队版支持更多同时在线设备与定制路由，方便把会议、代码仓库与内部系统走指定出口，减少公共网络波动影响。

学习与开发调试

开发者可使用订阅在多台电脑与手机间同步规则，配合分流实现国内直连、国际代理的日常工作流。

客户端选择

免流(EMO) 提供标准机场订阅（Clash / Sing-box 等兼容格式）。请根据系统选择成熟客户端，务必从各客户端官方渠道获取安装包，本页仅提供选择建议与导入思路，不托管第三方安装文件。

Windows

推荐 Clash Verge Rev 或 v2rayN。导入订阅后开启系统代理或 TUN 模式，可按域名与进程分流。

macOS

可选用 ClashX.Meta、Stash 或 Surge。注意授权网络扩展，订阅更新建议开启自动刷新。

iOS / iPadOS

常用 Shadowrocket、Stash、Quantumult X。通过扫码或粘贴订阅 URL 添加，按需开启代理与分流规则。

Android

Clash Meta for Android、Surfboard 或 Nekobox 均可。建议开启分应用代理，避免即时通讯被不必要代理。

其他

路由器可刷写支持的固件后导入订阅；Linux 可使用 clash / sing-box 命令行核心。选择与自己技术栈匹配的方案即可。

操作说明

第一步：选择并开通套餐

根据流量与设备数量选择基础版、旗舰版或团队版。开通后在用户中心复制订阅链接，请妥善保管，勿公开分享。

第二步：下载并安装客户端

前往对应系统的客户端官方站点完成下载与安装。安装完成后不要急于添加不明配置，先确认应用来源可信。

第三步：导入机场订阅

在客户端中选择“从 URL 更新 / 添加订阅”，粘贴免流(EMO) 提供的订阅地址，执行更新。成功后即可看到节点列表。

第四步：选择节点并开启代理

延迟测试后挑选合适地区节点。日常浏览可用自动选择或负载均衡，游戏与会议可手动指定 IPLC 或低延迟线路。

第五步：规则与分流

建议使用规则集让国内网站直连、国际流量走代理，既能省流量也能提升访问速度。遇到异常时先关闭代理排查是否为本地网络问题。

节点与性能说明

免流(EMO) 节点池覆盖亚洲主要地区以及北美、欧洲常用入口，普通线路适合网页与视频，IPLC 更适合对延迟敏感的应用。实际速度受本地宽带、时段与目标站点影响，请以客户端测速为准。我们持续优化峰值时段容量，但不对具体速率作绝对承诺。

常见问题

免流(EMO) 是什么？和普通 VPN 有何不同？

免流(EMO) 是提供机场订阅的网络加速服务。用户通过兼容客户端导入订阅即可使用多个节点，而不是单一应用内置线路。这种方式便于按设备自由选择 Clash、Shadowrocket 等工具，并自定义分流规则。

如何获取官网客户端下载与订阅？

请先在本站了解套餐后完成开通，再于用户中心复制订阅链接。客户端请分别前往 Clash、Shadowrocket、v2rayN 等项目的官方页面下载，以免安装被篡改的版本。本页锚点“客户端选择”列出了常见组合。

支持哪些设备同时在线？超出会怎样？

基础版 3 台、旗舰版 5 台、团队版 20 台。超出可能被限制新连接或挤占旧会话，建议按实际终端数量选套餐，或将不常用设备下线。

流量用尽或到期后如何处理？

流量周期通常按自然月或开通日起算，用尽后加速会暂停，续费或升级套餐后恢复。年付用户同样按月额度使用，请在客户端或用户中心留意剩余流量。

流媒体打不开或显示未解锁怎么办？

请切换至标注支持解锁的节点，并清除应用缓存后重试。部分平台会检测 IP 信誉，遇到风控可更换同地区备用节点。基础版仅含基础解锁，完整原生解锁请使用旗舰版或团队版节点。

游戏加速需要怎样设置？

优先选择带 IPLC 或游戏优化标识的节点，并在客户端为游戏进程开启代理、关闭无关下载。若游戏自带加速器，注意不要双重代理造成绕路。延迟以游戏内显示为准，可多试几个入口。

订阅链接泄露了怎么办？

立即在用户中心重置订阅链接，旧链接将失效。不要把订阅发到群组或截图公开。团队版如需多人使用，应通过正规席位分配而非共享同一地址。
